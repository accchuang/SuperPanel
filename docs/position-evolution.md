# Position evolution

首页以区间为单位，提供净多/净空规模曲线、日间净变化、席位日期热力图、
单席位方向曲线及期末减期初的变化排序。

GET /evolution?symbol=RB&days=30&start=2026-08-01&end=2026-09-04

- start/end 可选；days 为区间内最近 N 个有数据日期，最大 120。
- daily 汇总当日所有已收录席位，不使用期末 Top5 代替历史总体。
- brokers 包含区间席位并集，各日期缺失值为 null。
- change 为区间首尾净持仓之差；缺失任一端或只有一天时为 null。
- 日间变化仅在相邻记录日席位集合一致时计算。
- 热力图统一使用区间最大绝对净持仓作色阶。
- 原 CSV 未披露的一侧持仓可能已经被导入脚本填零，图表无法还原未知值。
- P/OI/Y 已导入东方财富真实历史：2026-07-27 至 2026-09-04，共 30 个交易日，每品种每日 20 个席位，合计 1,800 条。CSV：data/real_oils_20260727_20260904.csv。
- 数据按品种聚合多个合约，再取前 20 席位，不等同于主力合约；已过滤“总量增减”等汇总行。JM 仍只有 2026-09-04 真实样本，RB 等其他品种仍为 mock。
- 此次替换前的 SQLite 备份：data/dev_before_real_oils_20260907_155952.db。
